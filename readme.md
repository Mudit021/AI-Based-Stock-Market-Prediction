# AI-Powered Stock Market Predictor

An end-to-end Machine Learning project that analyzes and predicts stock prices using historical S&P 500 stock market data.

## Features

- Interactive stock dashboard
- Candlestick charts
- Technical indicators
- AI-powered price prediction
- Buy/Sell signals
- RSI analysis
- Moving averages
- Volatility analysis

## Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- XGBoost
- Scikit-learn

## Machine Learning

The project uses XGBoost Regression for forecasting future stock prices using engineered financial indicators such as:

- Moving Averages
- RSI
- MACD
- Bollinger Bands
- Volatility
- Daily Returns

## Deployment

The application is deployed using Streamlit Cloud.
https://ai-based-stock-market-prediction.streamlit.app/

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app/app.py
```

## Dataset

S&P 500 Historical Stock Market Dataset
